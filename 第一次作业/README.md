## 实验内容

使用 Python 与开源密码库 [`cryptography`](https://cryptography.io/) 完成五项实验：

1. AES-256-GCM 对称加解密与认证标签校验
2. RSA-2048 密钥生成与 OAEP 加解密
3. RSA-PSS 数字签名与验证
4. ECDH P-256 密钥交换与 HKDF-SHA256 会话密钥派生
5. SHA-256 摘要计算

## 运行

```bash
cd 任务二_开源密码库实验
python -m pip install -r requirements.txt
python run_experiment.py 01
```

编号可取 `01` 至 `05`，分别对应上述五项实验。代码中的密钥、Nonce 与随机盐均在运行时生成，因此每次输出的密文、签名与摘要上下文可能不同。
