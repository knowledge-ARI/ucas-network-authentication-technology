## 实验结果

实验于 2026-10-27 完成，共捕获 3,496 包。报告选取 `tcp.stream == 26`：帧 1168、1171、1174、1178 分别展示 ClientHello、ServerHello、密钥交换和加密应用数据。样本连接使用 TLS 1.2、X25519、RSA-PSS-SHA256 握手签名与 AES-128-GCM 记录保护。

成功登录来自操作者确认。未解密 HTTP 登录请求体，因此未确定具体口令提交报文、前端额外口令处理或后端存储算法。
